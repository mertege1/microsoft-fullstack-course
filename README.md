# Microsoft Full-Stack Developer Eğitimi Proje Arşivi

Bu depo, Microsoft Full-Stack Developer eğitim programı kapsamında geliştirdiğim projelerin ve teknik çalışmaların tek bir çatı altında toplandığı ana dizindir.

---

## Projeler

### 01. Kişisel Portfolyo Sitesi (./01-portfolio-website)
Eğitim programının front-end temelleri modülü için geliştirilmiş kişisel web sitesidir.
* **Kullanılan Teknolojiler:** HTML5, CSS3 (Grid, Flexbox, Değişkenler), Vanilla JavaScript (DOM Manipülasyonu)
* **Özellikler:** Mobil uyumlu (responsive) tasarım, erişilebilirlik standartları ve dinamik gece/gündüz modu altyapısı.

### 02. EventEase - Etkinlik Yönetim Uygulaması (./02-blazor-app)
Blazor mimarisi kullanılarak geliştirilmiş, modern ve dinamik bir tek sayfa uygulamasıdır (SPA).
* **Kullanılan Teknolojiler:** C#, .NET 8, Blazor, HTML/CSS
* **Özellikler:** * Gelişmiş durum yönetimi (State Management) ile anlık katılımcı takibi (Attendance Tracker).
  * Çift yönlü veri bağlama (Two-Way Data Binding) ve canlı form doğrulaması (Input Validation).
  * Modern, estetik arayüz tasarımı ve sayfa yenilemesiz hızlı gezinme (Routing).
